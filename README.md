# XOX Oyunu (Tic-Tac-Toe)

C# Windows Forms kullanılarak geliştirilmiş, bilgisayara karşı oynanan klasik bir XOX oyunudur.

## Özellikler
- Bilgisayara karşı oyun modu.
- Kazananı ve beraberliği otomatik tespit etme.
- Basit ve kullanıcı dostu arayüz.

## Kullanılan Teknolojiler
- C#
- Windows Forms
